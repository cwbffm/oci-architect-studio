# Temas

O Studio oferece 38 variantes clássicas em 19 famílias, com modos claro e escuro. O tema inicial é Claro; preferências válidas já salvas são preservadas. O catálogo inclui Dracula, GitHub, Monokai, VS Code, Oracle Redwood, Ayu e outras famílias.

Temas especiais, fundos decorativos e a aba de temas especiais foram removidos. Projetos antigos com esses temas são migrados para Claro ou Escuro conforme o modo anterior, preservando os recursos. As cores de destaque continuam sempre visíveis e as preferências de leitura são independentes do projeto.

Execute `npm run test:themes` para verificar contraste, persistência, layout e migração dos temas removidos.

A interface usa lista dupla de temas com busca, modos compactos e painel fixo com abas Texto, Código e Espaçamento. As cores de destaque e a personalização continuam no mesmo painel.
